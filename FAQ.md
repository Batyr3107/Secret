# FAQ - Часто задаваемые вопросы

## 📱 Общие вопросы

### Что такое Context Keeper?
**Context Keeper** - это умное приложение для заметок о контактах, которое автоматически показывает важную информацию при входящих звонках. Например, вы можете записать "Дочери Рита и Гита, 3 и 1 год", и при звонке эта информация появится на экране.

### На каких платформах работает?
- **Android** - полная поддержка с overlay окном
- **iOS** - базовая поддержка через push-уведомления

### Бесплатно ли приложение?
Да, приложение полностью бесплатное и open-source.

## 🔒 Безопасность и приватность

### Где хранятся мои данные?
Все данные хранятся **локально на вашем устройстве** в защищенной SQLite базе данных. Никакие данные не отправляются на внешние серверы (кроме FCM токена для iOS push-уведомлений).

### Безопасно ли хранить личную информацию?
Да, полностью безопасно. Данные:
- ✅ Хранятся локально
- ✅ Доступны только вашему приложению
- ✅ Не синхронизируются с облаком
- ✅ Полностью под вашим контролем

### Можно ли экспортировать данные?
В текущей версии (1.0.0) нет, но эта функция запланирована в версии 2.0.

## 🤖 Android

### Как работает показ заметок на Android?
При входящем звонке приложение:
1. Определяет номер звонящего
2. Ищет заметку в базе данных
3. Показывает overlay окно поверх экрана звонка
4. Автоматически скрывает окно после завершения звонка

### Почему overlay не показывается?
Проверьте:
1. Разрешение "Показ поверх других окон" включено
2. Разрешение "Доступ к телефону" включено
3. На Xiaomi/Huawei: включите автозапуск в настройках

### Как включить автозапуск на Xiaomi?
1. Настройки → Приложения → Context Keeper
2. Автозапуск → Включить
3. Управление батареей → Без ограничений

### Работает ли на Android 14?
Да, приложение протестировано на Android 7.0 - 14.0.

## 🍎 iOS

### Почему нет overlay на iOS?
Apple не позволяет приложениям показывать overlay поверх экрана звонка по соображениям безопасности. Вместо этого мы используем push-уведомления.

### Как работают уведомления на iOS?
Для работы на iOS требуется backend сервер, который:
1. Получает webhook о входящем звонке
2. Находит заметку в вашей базе
3. Отправляет push-уведомление на ваш iPhone

### Почему требуется backend для iOS?
iOS не позволяет приложениям работать в фоне для мониторинга звонков. Поэтому нужен внешний сервер, который будет отслеживать звонки и отправлять уведомления.

### Как настроить backend?
См. [SETUP_GUIDE.md](./SETUP_GUIDE.md) раздел "iOS Backend Setup"

## ⚙️ Использование

### Как создать заметку?
1. Откройте приложение
2. Нажмите кнопку "+" внизу справа
3. Выберите контакт из списка
4. Введите заметку (например: "Дочери Рита и Гита, 3 и 1 год")
5. Нажмите "Сохранить"

### Можно ли редактировать заметки?
Да! Нажмите на заметку в списке, затем кнопку редактирования (карандаш) в правом верхнем углу.

### Как удалить заметку?
1. Откройте детали заметки
2. Нажмите кнопку удаления (корзина) вверху
3. Подтвердите удаление

### Есть ли поиск по заметкам?
Да, используйте поле поиска вверху главного экрана. Поиск работает по именам контактов и содержимому заметок.

### Есть ли лимит на количество заметок?
Технический лимит: 10,000 заметок. Практически этого более чем достаточно.

### Какой максимальный размер заметки?
Максимум 5,000 символов на одну заметку.

## 🔧 Технические вопросы

### Какие разрешения нужны?

**Android:**
- ✅ Доступ к контактам - для выбора контакта
- ✅ Доступ к телефону - для отслеживания звонков
- ✅ Показ поверх других окон - для overlay
- ✅ Уведомления - для работы в фоне

**iOS:**
- ✅ Доступ к контактам - для выбора контакта
- ✅ Уведомления - для push-уведомлений

### Разряжает ли приложение батарею?
Нет, приложение оптимизировано для минимального потребления батареи:
- Использует foreground service только когда нужно
- Не делает постоянных запросов к сети
- База данных с индексами для быстрого доступа

### Сколько места занимает?
- APK размер: ~15-20 MB
- База данных: зависит от количества заметок (обычно < 1 MB)

### Требуется ли интернет?
Нет, приложение работает полностью офлайн. Интернет нужен только для:
- iOS push-уведомлений (требует backend)
- Загрузки приложения из store

## 🐛 Проблемы и решения

### Приложение крашится при запуске
1. Убедитесь что версия Android >= 7.0 или iOS >= 12.0
2. Переустановите приложение
3. Очистите кэш приложения
4. Проверьте наличие свободного места на устройстве

### Не находит контакт при поиске
Убедитесь что:
1. У контакта есть номер телефона
2. Контакт сохранен в телефонной книге устройства
3. Приложение имеет разрешение на доступ к контактам

### Overlay мигает/исчезает сразу
Это может быть из-за:
1. Приложения для блокировки рекламы
2. Ограничений производителя (Xiaomi, Huawei)
3. Режима энергосбережения

**Решение:** Добавьте Context Keeper в исключения энергосбережения

### Заметка не показывается при звонке
Проверьте:
1. ✅ Номер в заметке совпадает с номером звонящего
2. ✅ Все разрешения выданы
3. ✅ Foreground service запущен (Android)
4. ✅ Backend настроен (iOS)

### Не работает поиск
Попробуйте:
1. Подождите 300ms после ввода (debounce)
2. Введите минимум 2 символа
3. Проверьте раскладку клавиатуры
