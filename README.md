# Context Keeper 📱

Умное приложение для заметок о контактах, которое показывает важную информацию при входящих звонках.

## 🎯 Что это такое?

Записывайте важную информацию о ваших контактах (например, "дочери Рита и Гита, 3 и 1 год"), и при входящем звонке эта информация автоматически отобразится на экране. Теперь вы всегда будете в контексте жизни собеседника!

## ✨ Возможности

- 📝 Создание заметок о любых контактах
- 📞 Автоматический показ заметок при входящих звонках
- 🔍 Поиск по контактам и заметкам
- 📱 Полная поддержка Android
- 🍎 Поддержка iOS через push-уведомления
- 🎨 Современный Material Design UI

## 🚀 Установка

### Требования

- Flutter SDK 3.0.0 или выше
- Dart 3.0.0 или выше
- Android SDK (для Android)
- Xcode (для iOS)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd context_keeper
```

2. Установите зависимости:
```bash
flutter pub get
```

3. Для iOS (необходима дополнительная настройка Firebase):
```bash
cd ios
pod install
cd ..
```

## 🔧 Настройка

### Android

1. Минимальная версия SDK: **24** (Android 7.0)
2. Целевая версия SDK: **34** (Android 14)

Необходимые разрешения (добавлены автоматически):
- `READ_PHONE_STATE` - для отслеживания звонков
- `READ_CONTACTS` - для доступа к контактам
- `SYSTEM_ALERT_WINDOW` - для показа overlay
- `POST_NOTIFICATIONS` - для уведомлений

### iOS

1. Минимальная версия iOS: **12.0**

Для полноценной работы на iOS требуется:

#### Вариант 1: Push-уведомления (Рекомендуется)

1. Настройте Firebase проект:
   - Создайте проект в [Firebase Console](https://console.firebase.google.com/)
   - Добавьте iOS приложение
   - Скачайте `GoogleService-Info.plist` и поместите в `ios/Runner/`

2. Настройте Apple Developer Account:
   - Включите Push Notifications capability
   - Загрузите APNs ключ в Firebase

3. Настройте backend для отправки push-уведомлений при входящих звонках

#### Вариант 2: CallKit (Продвинутый)

Требует дополнительной нативной разработки на Swift:
- Реализация `CXProvider` и `CXCallController`
- Интеграция с VoIP push notifications
- Регистрация CallKit extension

## 🎮 Использование

### 1. Первый запуск

При первом запуске приложение запросит необходимые разрешения:

**Android:**
- Доступ к контактам ✅
- Доступ к телефонным звонкам ✅
- Показ поверх других окон ✅
- Уведомления ✅

**iOS:**
- Доступ к контактам ✅
- Уведомления ✅

### 2. Создание заметки

1. Нажмите кнопку "+" в правом нижнем углу
2. Выберите контакт из списка
3. Напишите заметку (например: "Дочери Рита и Гита, 3 и 1 год. Работает в IT компании")
4. Нажмите "Создать заметку"

### 3. При входящем звонке

**Android:**
- Автоматически появится overlay-окно с заметкой
- Окно можно закрыть крестиком
- Окно исчезает после завершения звонка

**iOS:**
- Придет push-уведомление с заметкой
- Для автоматической работы требуется настройка backend

## 🔐 Безопасность и приватность

- ✅ Все данные хранятся локально на устройстве
- ✅ Нет отправки данных на внешние серверы (кроме FCM для iOS)
- ✅ Полный контроль над своими данными
- ✅ Можно удалить все данные в любой момент

## 🐛 Известные ограничения

### Android
- На Android 10+ требуется специальное разрешение для overlay
- На некоторых устройствах (Xiaomi, Huawei) требуется дополнительная настройка autostart

### iOS
- Overlay поверх экрана звонка невозможен из-за ограничений iOS
- Требуется backend для push-уведомлений
- Уведомления могут не показываться если телефон заблокирован
