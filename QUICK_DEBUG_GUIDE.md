### ❌ Если черный экран, ищите где остановилось:

#### Проблема A: Остановилось на "🚀 Запуск приложения..."
**Причина**: Не запустился main() или runApp()
**Решение**: Проблема в Flutter runtime или AndroidManifest

#### Проблема B: Остановилось на "🔐 Начинаем проверку биометрии..."
**Причина**: AuthGate._checkBiometric() зависла
**Решение**: Проблема в SharedPreferences или BiometricService

#### Проблема C: Остановилось на "🔐 Биометрическая защита в настройках:"
**Причина**: BiometricService.isBiometricEnabled() зависла
**Решение**: Проблема с SharedPreferences.getInstance()

#### Проблема D: Остановилось на "🗄️ Инициализация базы данных..."
**Причина**: DatabaseService.database зависла
**Решение**: Проблема с sqflite или файловой системой

#### Проблема E: Остановилось на "🔒 Проверка разрешений..."
**Причина**: HomeScreen._checkPermissions() зависла
**Решение**: Проблема с permission_handler

#### Проблема F: Вообще нет логов
**Причина**: Приложение крашится до main()
**Решение**: Смотрите полный logcat без фильтра

## Шаг 3: Полная отладка (если Step 1-2 не помогли)

```bash
# Получите ВСЕ логи (без фильтра)
adb logcat > full_log.txt

# Установите и запустите приложение
adb install -r build\app\outputs\flutter-apk\app-release.apk

# Подождите 10 секунд, нажмите Ctrl+C
# Откройте full_log.txt и найдите строки с "context_keeper" или "FATAL"
```

## Шаг 5: Проверка базовых вещей

```bash
# Проверьте версию Android
adb shell getprop ro.build.version.sdk

# Должна быть >= 24 (Android 7.0)

# Проверьте свободное место
adb shell df /data

# Должно быть хотя бы 100MB свободно

# Проверьте что приложение установлено
adb shell pm list packages | findstr context_keeper
```
