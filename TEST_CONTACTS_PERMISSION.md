# 📇 Тест доступа к контактам

## Проблема
Вы дали разрешение на контакты, но приложение не видит их.

## Возможные причины

### 1️⃣ Конфликт между плагинами
В приложении используются **два плагина** для работы с разрешениями:
- `flutter_contacts` - для доступа к контактам
- `permission_handler` - для проверки разрешений

Они могут конфликтовать друг с другом.

### 2️⃣ Разрешение не запрошено правильно
Android 11+ требует специального подхода к разрешениям.

```bash
# Запустите мониторинг логов
adb logcat | findstr "📇 🚀 🔐 🗄️ 📝 ✅ ❌"
```

## 🔍 Шаг 2: Тест доступа к контактам

1. Откройте приложение на телефоне
2. Дождитесь загрузки главного экрана
3. Нажмите кнопку **"+ Новая заметка"**
4. Нажмите на **"Выберите контакт"**

### Что должно быть в логах:

```
📇 Запрос разрешения на контакты...
📇 Результат запроса разрешения: true
📇 Загрузка контактов...
📇 Загружено контактов: 150
```

### Если видите:
```
📇 Запрос разрешения на контакты...
📇 Результат запроса разрешения: false
❌ Разрешение на контакты не получено
```

**Причина:** Система не дала разрешение.

**Решение:**
1. Откройте **Настройки Android** → **Приложения**
2. Найдите **Context Keeper**
3. Перейдите в **Разрешения**
4. Убедитесь что **Контакты** включены
5. Если нет - включите вручную
6. Вернитесь в приложение и попробуйте снова

---

## 🔍 Шаг 3: Проверка через настройки системы

```bash
# Проверьте какие разрешения даны приложению
adb shell dumpsys package com.example.context_keeper | findstr "permission"
```

Должна быть строка:
```
android.permission.READ_CONTACTS: granted=true
```

Если `granted=false`, значит система не дала разрешение.

---

## 🔍 Шаг 4: Проверка версии Android

```bash
# Узнайте версию Android
adb shell getprop ro.build.version.sdk
```

Если версия **>= 30** (Android 11+), то нужна специальная настройка в AndroidManifest.xml.

Проверим что она есть:

```xml
<!-- В AndroidManifest.xml должно быть: -->
<uses-permission android:name="android.permission.READ_CONTACTS"/>
```

## 🚨 Если ничего не помогает

### Вариант A: Полная переустановка

```bash
# Полное удаление с данными
adb uninstall com.example.context_keeper

# Очистка кеша
adb shell pm clear com.example.context_keeper

# Установка заново
adb install build\app\outputs\flutter-apk\app-release.apk
```

### Вариант B: Ручная выдача разрешения через ADB

```bash
# Дайте разрешение через ADB
adb shell pm grant com.example.context_keeper android.permission.READ_CONTACTS

# Проверьте что разрешение дано
adb shell dumpsys package com.example.context_keeper | findstr "READ_CONTACTS"
```
