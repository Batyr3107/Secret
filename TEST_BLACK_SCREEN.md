# 🧪 Тест черного экрана - ПОШАГОВАЯ ИНСТРУКЦИЯ

## У вас есть 2 версии приложения:

### 1️⃣ **app-simple-test.apk** (40.6 MB) - ТЕСТОВАЯ УПРОЩЕННАЯ
- Без БД, без биометрии, без сервисов
- Показывает просто зеленую галочку и текст
- Если ЭТА версия работает → проблема в сервисах
- Если ЭТА версия не работает → проблема в Android/Flutter setup

### 2️⃣ **app-release.apk** (47.1 MB) - ПОЛНАЯ ВЕРСИЯ
- Со всеми исправлениями
- С таймаутами и защитами
- Должна работать, но если не работает - смотрим логи

---

## 📋 ШАГ 1: Тест простой версии

```bash
# Установите простую версию
adb install -r build\app\outputs\flutter-apk\app-simple-test.apk

# Откройте приложение на телефоне
```

### ✅ Если видите зеленую галочку и текст "ПРИЛОЖЕНИЕ РАБОТАЕТ!"
**Значит:** Flutter работает нормально, проблема в сервисах полной версии

### ❌ Если черный экран
**Значит:** Проблема в Android setup или Flutter runtime (не в нашем коде!)

---

## 📋 ШАГ 2: Тест полной версии с логами

```bash
# Удалите простую версию
adb uninstall com.example.context_keeper

# Очистите логи
adb logcat -c

# Установите полную версию
adb install -r build\app\outputs\flutter-apk\app-release.apk

# Запустите приложение И СРАЗУ смотрите логи
adb logcat | findstr "🚀 🔐 🗄️ 📝 📞 🔔 ✅ ❌ ⚠️ 🔒 FATAL"
```

### Что должно быть в логах:
```
🚀 Запуск приложения...
🔐 Начинаем проверку биометрии...
🔐 Биометрическая защита в настройках: false
🔐 Результат проверки биометрии: false
🔓 Биометрия не включена, пропускаем проверку
🗄️ Инициализация базы данных...
✅ База данных инициализирована
📝 Загрузка заметок из БД...
✅ Загружено 0 заметок
🔒 Проверка разрешений...
🔒 Результат проверки разрешений: false
```

### Где остановилось?
- **После "🚀"** → main() не запустился
- **После "🔐 Начинаем"** → AuthGate зависла
- **После "🔐 настройках:"** → BiometricService зависла
- **После "🗄️"** → DatabaseService зависла
- **После "📝"** → Provider зависла
- **После "🔒"** → HomeScreen зависла

## 📋 ШАГ 3: Если ничего не помогло - полный лог

```bash
adb logcat > full_log.txt
```

Запустите приложение, подождите 10 секунд, нажмите Ctrl+C.
Откройте `full_log.txt` и найдите строки с "FATAL" или "context_keeper"

## 💡 Если простая версия работает, а полная нет:

Это значит проблема в одном из:
- DatabaseService (sqflite)
- BiometricService (SharedPreferences)
- PhoneService (permissions)
- ContactNotesProvider (загрузка из БД)
- HomeScreen (проверка permissions)

Логи покажут где именно!
